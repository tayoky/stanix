Welcome to Stanix!
Stanix is a 64bit made from scratch operating system for the x86_64 architecture with its own kernel, libc, terminal emulator, shell and userspace capable of running programs such as binutils, tash (homemade shell), tcc, MESA(OpenGL), SDL, or doom.  
To see a list of commands run "ls /usr/bin" and "ls /bin".
A list of devices found by the kernel can be seen by running "ls /dev".
See the documentation in /usr/share/doc or at https://tayoky.github.io/stanix or the repo at https://github.com/tayoky/stanix for more informations.
